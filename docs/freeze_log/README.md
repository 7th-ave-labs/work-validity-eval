# Freeze logs (one file per experiment)

Each run or freeze you care about for reproducibility should get its **own** markdown file in this folder (for example `2026-04-20_pipeline-v0.1.0.md`). Copy `_experiment_template.md` to a new name before you run, then fill in parameters and outputs after the run.
